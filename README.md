One line, in the voice of the Moon replying at last to the wishes, howls and
late-night promises of everyone staring up at it.

> In 1987 a boy in Dayton promised me he'd never lie again if his dog came home. The dog came home. The boy is a senator now.

`main.ts` (Node 22) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). 123 characters — inside the 1–240 gate.

## Run

```sh
node main.ts
cat /output/entry.txt
```
